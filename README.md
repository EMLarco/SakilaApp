# SakilaApp – Aplicación web con ASP.NET Core MVC y base de datos Sakila

## Descripción
Aplicación web para la gestión de una tienda de alquiler de películas. Permite CRUD de películas, actores, clientes, categorías, alquileres, inventarios y tiendas. Incluye autenticación (registro, login, logout) con ASP.NET Core Identity, validaciones con DataAnnotations, diseño responsivo con Bootstrap 5 y eliminación lógica (soft delete).

## Tecnologías utilizadas
- ASP.NET Core MVC (.NET 10.0)
- Entity Framework Core (10.0.x)
- SQL Server (Developer Edition)
- ASP.NET Core Identity
- Bootstrap 5
- jQuery Validation Unobtrusive

## Requisitos previos
- Visual Studio 2022 o superior
- .NET SDK 8.0
- SQL Server (instancia `DESKTOP-8O8V3AI\MSSQLSERVER01` o ajustar cadena de conexión)
- SQL Server Management Studio (SSMS) opcional
